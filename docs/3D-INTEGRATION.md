# Контракт слотов 3D

Партнёр берёт этот репозиторий и вставляет 3D сам. Вёрстка, ритм секций,
загрузчик, обработка ошибок и fallback уже реализованы. Меняется только
содержимое сцены.

## Что где лежит

```
src/components/three/
  IntroScene.tsx          слот интро      → scenes/intro.scene.tsx
  FloorPlan3D.tsx         слот планировки → scenes/floorplan.scene.tsx
  VirtualTour.tsx         слот тура       → scenes/tour.scene.tsx
  SceneSlot.tsx           обвязка, общая для всех трёх. Не трогать.
  SceneErrorBoundary.tsx  граница ошибки. Не трогать.
  webgl.ts                проверка поддержки. Не трогать.
  types.ts                контракт
  scenes/GpuRelease.tsx   освобождение видеопамяти. Оставить в сцене.
```

**Трогать только файлы в `scenes/`.** Всё остальное — обвязка.

## Контракт

| Проп или событие | Назначение |
|---|---|
| `active: boolean` | сцена рендерится только когда видна; при `false` кадры не считаются |
| `onReady()` | сцена готова — снимаем экран загрузки |
| `onProgress(n)` | процент для индикатора, 0–100 |
| `onError(error)` | падаем в статичный fallback, не в белый экран |

`onReady` зовётся один раз, после первого готового кадра, а не по событию
загрузки модели: между ними компиляция шейдеров, и на слабом ноутбуке это
заметная пауза.

`onError` вместо собственного экрана ошибки. Исключение, брошенное при
рендере, тоже перехватывается — граница ошибки уже стоит.

## Что обвязка делает сама

- Ленивая загрузка через `dynamic(..., { ssr: false })` — `three` трогает
  `window` на импорте.
- `Suspense` и единый индикатор прогресса для всех трёх слотов.
- Граница ошибки: падение сцены не роняет страницу.
- `IntersectionObserver` с запасом 200px: за пределами вьюпорта `active`
  становится `false`, а через пять секунд сцена размонтируется и отдаёт
  видеопамять. Возврат в кадр монтирует её заново.
- `GpuRelease` внутри `<Canvas>` зовёт `gl.dispose()` и
  `gl.forceContextLoss()`. Браузер держит не больше шестнадцати
  WebGL-контекстов, а слотов на странице три.
- Проверка WebGL до монтирования; нет поддержки — сразу fallback.

## Бюджеты веса

| Слот | Бюджет |
|---|---|
| Интро | ≤ 8 МБ |
| Планировка | ≤ 5 МБ |
| Тур | внешний |

На медленном 4G 8 МБ качаются около сорока секунд. Больше человек не ждёт.

## Интро: отдельные требования

Сцена заканчивается **внутри** помещения. Первый экран сайта — тот же ракурс,
только статичный. Шва между интро и страницей быть не должно.

- Кнопка «Пропустить» с первой секунды, крупная, не в углу.
- Показ один раз за сессию.
- Цена и площадь видны прямо на интро, поверх сцены.
- Жёсткий таймаут 4 секунды — уже реализован в `IntroScene.tsx` через
  `INTRO_TIMEOUT_MS`. Не готово — уходим на сайт.
- На мобильном и при `prefers-reduced-motion` не запускается.

Проверка после сборки: замер на эмуляции медленного 4G, через сколько секунд
от открытия видна цена. Больше двух — интро отключается. Решает замер.

## Источники геометрии

План верен по планировке и количеству, рендеры — по мебели и отделке.
Расхождение по геометрии помещения решается в пользу плана, по обстановке —
в пользу рендеров.

## Открытый пункт

`fallback` во всех трёх слотах сейчас `null`: статичных кадров нет.
Когда появятся, туда ставится изображение — не серый прямоугольник с
подписью.

## Как включить сцену

Слоты выключены флагом. Пока флаг `false`, слот не монтирует ничего:
`dynamic`-импорт не вызывается, `IntersectionObserver` не вешается, чанк с
`three` и React Three Fiber в сеть не уходит, а секция не резервирует под
сцену пустой блок. Замерено: одна пустая заглушка интро тянула 228,7 КБ по
проводу и держала 995px первого экрана ради сцены, которая ничего не рисует.

Флаги лежат в `src/config/scenes.ts`:

```ts
export const SCENES_READY = {
  intro: false,
  floorPlan: false,
  tour: false,
} as const;
```

Порядок такой: вставляете сцену в соответствующий файл в `scenes/`, потом
переключаете свой флаг в `true` — и только тогда слот появляется на странице.
Флаг переключается ровно один, для своей сцены; чужие не трогать. После
переключения обязателен замер: на эмуляции медленного 4G цена в hero должна
оставаться видимой не позже двух секунд от открытия. Не укладывается — сцена
возвращается за флаг.
